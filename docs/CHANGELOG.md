## [1.0.0] - 2026-09-19

首个正式版本基线。此前功能全部并入 1.0，版本号从此重新起算。

### Added

- **广发投研连接器**：标准 OAuth2 动态客户端注册 + PKCE 授权，本地回调捕获授权码，
  令牌存本机并自动 refresh，授权后可列出并调用广发 MCP 全部工具。
- **IMA 知识库连接器**：支持 OpenAPI（ClientId / ApiKey）与微信扫码两种接入，
  可搜索 / 新建 / 追加笔记，检索与导入知识库内容。
- **行情数据源双轨**：未接通通达信主站时自动降级到网络行情源，沪 / 深 / 北交所报价表不再开天窗。
- **股票代码搜索下拉**：报价表支持输入代码或中文名即时联想，↑↓ 选择、Enter 直接看 K 线。
- **点击看 K 线**：点报价表任意一行立即选中该标的并自动切到 K 线页。
- **电视画面深度验证**：刷新时逐条跟随 m3u8 变体、拉取分片解析 TS / fMP4 容器确认真的有视频轨，
  确认有画面的频道打「✓画面」标记。
- **电脑助手**：垃圾清理、软件卸载、网络修复、端口扫描、测速、网络工具箱与系统报告。
- 全新软件图标与「关于」页品牌图（透明背景）。
- 重写应用内「帮助中心」与「关于」页，按当前真实模块与架构描述。

### Changed

- 行情工作区不再强制依赖通达信主站：未接通时顶部标注数据源并自动切换。
- K 线页签标题与空态文案改为与数据源一致，不再写死「通达信」。
- 五档盘口仅在数据源提供时展示，否则给出「接入通达信后可看」的说明。
- 插件目录整理为 25 个、8 大分类；上下文压缩器固定钉在能力池第一位常驻。
- 顶栏人像图标可展开「电脑助手」与「电视」两个附加工具入口。

### Improved

- 临时网络故障（429 / 5xx / 超时）不再误判为频道失效，只重试不删除。
- 报价表分页与排序在无主站时改为服务端分页，页码与内容始终一致。

## [0.1.0] - 2026-09-17

### Added
- IMA 微信扫码连接支持保存、状态验证和清除，浏览器档案持久保存到本机用户目录。
- 模型目录改为“从上游获取”，按所选供应商的 API 返回格式读取上游模型列表。

- 多场景智能体协作会话。
- 岗位数字人与先哲人格卡。
- 插件工具与智能体自进化。
- 知识库与先哲书库。
- Token 用量与成本看板。
- Electron 桌面外壳。
- Capacitor 移动端构建支持。
- 记事本功能，支持文本、图片、语音、视频；媒体存 IndexedDB，可导出到知识库。
- 三维交互式知识图谱。
- 本地 TDX 只读行情桥。
- 投资分析 AI 问话、多空辩论、情景推演与数据审计面板。
- 完整项目文档、发布说明与 GitHub 模板。

### Changed

- 问话功能不再提供离线假回答。
- 未配置联网大模型时，发送问话会立即弹出 API 设置窗口。
- 保存 API 参数后会自动继续刚才的问话。
- 模型请求失败改为显式提示，不回退到本地演绎。

### Improved

- 优化主题文字对比度与视觉层级。
- 优化知识库分类、文件预览与用量统计。
- 强化本地数据边界与 API Key 保护说明。
