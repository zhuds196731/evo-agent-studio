# Changelog

所有重要变更都会记录在本文件中。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)。

## [Unreleased]

### Added

- 新增记事本功能，支持文本、图片、语音、视频。
- 记事本媒体保存在 IndexedDB，支持应用内预览、播放和下载。
- 记事本内容与附件可选择导出到知识库。
- 记事本上传大小由用户设置，默认无限制。
- 新增三维交互式知识图谱。
- 新增本地 TDX 只读行情桥。
- 新增投资分析 AI 问话、多空辩论、情景推演与数据审计面板。
- 新增完整项目文档、发布说明与 GitHub 模板。

### Changed

- 问话功能不再提供离线假回答。
- 未配置联网大模型时，发送问话会立即弹出 API 设置窗口。
- 保存 API 参数后会自动继续刚才的问话。
- 模型请求失败改为显式提示，不回退到本地演绎。

### Improved

- 优化主题文字对比度与视觉层级。
- 优化知识库分类、文件预览与用量统计。
- 强化本地数据边界与 API Key 保护说明。

## [0.1.0] - 2026-09-17

### Added

- 多场景智能体协作会话。
- 岗位数字人与先哲人格卡。
- 插件工具与智能体自进化。
- 知识库与先哲书库。
- Token 用量与成本看板。
- Electron 桌面外壳。
- Capacitor 移动端构建支持。
