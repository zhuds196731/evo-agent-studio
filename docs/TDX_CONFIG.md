# 通达信行情源配置说明

## 设计边界

- 只连接 `[HQHOST]` 行情主站，用于读取 K 线和报价。
- `[INFOHOST2]` 与 `[DSHOST]` 目前只解析和展示，预留资讯和扩展市场能力。
- 不读取、不保存、不提交账号、密码、交易服务器或委托接口。
- 不修改通达信原目录文件。

## 默认配置

- 桌面端启动时会优先读取本机通达信配置：
  - 环境变量 `EVO_TDX_CONFIG`
  - 默认路径：`D:\我的专用灵动版V1.21\Connect.cfg`
- 如果没有找到本机配置，会使用内置默认配置：`public/tdx/Connect.default.cfg`。
- 用户在界面上保存的自定义配置只会保存在本应用中，不会回写通达信目录。

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `[USER]` | 保持空用户名、`SavePass=0`，用于声明不登录。 |
| `[HQHOST]` | 行情主站组，是当前实际使用的核心配置。 |
| `HostNum` | 行情主站数量，需要与实际条目一致。 |
| `PrimaryHost` | 首选主站编号；系统仍会自动探测并切换。 |
| `HostNameNN` | 主站显示名称。 |
| `IPAddressNN` | 主站地址，支持 IP 或域名。 |
| `PortNN` | 主站端口，普通行情多为 `7709`。 |
| `[INFOHOST2]` | 资讯主站组，当前仅解析和展示。 |
| `[DSHOST]` | 扩展市场数据站，当前仅解析和展示。 |

## 禁止添加

- `[WTHOST]`
- `[USERHOST]`
- 交易服务器地址
- 账号、密码、证书
- 自动下单、自动交易参数
