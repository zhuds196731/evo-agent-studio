# 用户指南

## 首次启动

1. 启动软件。
2. 进入「设置」。
3. 选择模型供应商。
4. 填写 API Key。
5. 选择模型。
6. 点击「保存设置」。
7. 如有必要，点击「测试连接」。

推荐先选择有免费额度的模型，例如 GLM-5.3-Flash 或其他厂商的免费模型。

## 协同会话

### 创建会话

1. 打开「协同会话」。
2. 选择场景：单人对话、单人对单人、单人对多人、小组对小组、汇报、问询、先哲咨询。
3. 点击「新建」。
4. 选择参与角色。
5. 发送问题。

### 常用操作

- 搜索：左侧会话栏可按标题或消息内容搜索。
- 置顶：点击会话右侧图钉。
- 重命名：双击标题，或点击标题旁的编辑按钮。
- 导出：右上角「导出」生成 Markdown 文件。
- 删除：右上角「删除会话」。

### 语音输入

点击输入框旁的麦克风按钮开始识别，再次点击结束。

## 岗位中心

- 查看内置岗位与自建岗位。
- 编辑职责、技能、KPI、汇报关系、语气。
- 上传头像或复制 AI 形象提示词。
- 一句话生成岗位草稿。

## 先哲堂

内置多个思想人物。每个先哲包含：

- 核心思想
- 思维框架
- 语言风格
- 代表著述
- 经典语录
- 擅长领域

可以点击「咨询」进入先哲思想咨询会话。

## 投资分析

### 分析流程

1. 输入标的。
2. 设置投资周期、风险偏好、最大仓位、止损和回撤约束。
3. 生成五层证据。
4. 查看指标、智能体报告、决策链和审计留痕。
5. 进入 AI 问话进行复盘、辩论或情景推演。

### 数据不足

系统不会编造缺失数据。若数据不足，指标会显示 `INSUFFICIENT_DATA`，结论会变为「数据不足，暂不决策」。

### AI 问话

AI 问话只基于当前证据包回答。可选模式包括：

- 严格无判断
- 严格判断
- 探索性

可选视角包括综合、宏观、行业、基本面、技术、情绪、风险和偏差。

## 知识库

1. 打开「知识库」。
2. 选择分类。
3. 点击「上传文件」。
4. 上传文档或图片。
5. 点击预览、下载或删除。

单文件默认上限 2MB。大文件建议继续使用「记事本」的 IndexedDB 媒体存储。

## 三维知识图谱

1. 打开「知识库」。
2. 切换到「三维图谱」。
3. 缩放、旋转或拖拽视图。
4. 点击节点查看知识详情。

图谱会随软件内岗位、人物、会话、插件、投资运行和知识文件增长而扩展。

## 记事本

### 新建笔记

1. 打开「记事本」。
2. 点击「新增笔记」。
3. 输入标题和正文。

### 添加媒体

支持：

- 图片
- 音频
- 视频

媒体保存在本机 IndexedDB，可在页面内直接预览或播放。上传大小由用户设置，留空或填 0 表示无限制。

### 保存到知识库

1. 勾选「允许保存到知识库」。
2. 对每个媒体附件勾选「入库」。
3. 点击「保存到知识库」。

正文和媒体会复制到知识库「个人笔记」分类。超过知识库 2MB 限制的媒体会保留在记事本，但不会入库。

## 常见问题

### 为什么不能离线问话？

问话功能必须使用联网大模型，避免离线模板生成误导性回答。未配置时软件会弹出 API 设置窗口。

### API Key 会上传吗？

不会。API Key 保存在本机，只用于调用你选择的模型服务商。

### 为什么视频没有入库？

知识库当前单文件上限为 2MB。大视频继续保存在记事本 IndexedDB 中。

### 为什么分析结论是“数据不足”？

因为关键数据缺失或样本数不足。系统拒绝编造指标，必须补充数据后重新分析。

### 如何迁移到新电脑？

旧电脑：设置 → 导出全部配置。  
新电脑：设置 → 导入配置。
