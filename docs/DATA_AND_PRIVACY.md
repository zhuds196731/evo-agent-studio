# 数据、隐私与安全说明

## 存储位置

| 数据 | 存储位置 | 说明 |
| --- | --- | --- |
| 岗位、人物、会话、插件、投资运行 | `localStorage` | 全局结构化状态 |
| API Key | `localStorage` | 仅本机保存 |
| 先哲书库 | IndexedDB `sea-books` | 保存 PDF/TXT/MD |
| 记事本媒体 | IndexedDB `evo-notepad` | 保存图片、音频、视频 |
| 提示词暂存 | `localStorage` | 按会话保存 |
| Token 账本 | `localStorage` | 用量与成本估算 |

## 上传行为

本软件没有中心化后端，不上传：

- 用户状态
- 会话内容
- 知识库文件
- 记事本媒体
- API Key

联网请求只发生在以下场景：

1. 调用你选择的大模型服务商。
2. 获取开源书籍文本或知识库数据源。
3. 获取金融行情、财报、行业或情绪数据。
4. 获取模型价格或行情接口数据。
5. 本地 TDX 只读桥连接行情主机。

## API Key 安全

- API Key 只保存在本机。
- 默认输入框隐藏 Key。
- 项目不会把 Key 写入日志。
- 不建议把导出的配置 JSON 发给别人。
- 如果怀疑泄露，应立即在模型服务商后台作废 Key。

## Electron 安全

`electron/main.cjs` 的安全配置：

- `contextIsolation: true`
- `nodeIntegration: false`
- 不开放远程调试，除非显式设置 `EVO_DEV_TOOLS=1`
- 加载本地 `dist/index.html`

## TDX 安全边界

`vite.tdxPlugin.mjs` 的设计边界：

- 只读取通达信行情主机配置。
- 不读取用户名和密码内容。
- 不自动登录。
- 不访问交易接口。
- 不提交订单。
- 请求体大小限制为 512KB。
- 连接和读取均有超时。

## 大模型安全

- 用户问话必须配置联网大模型。
- 系统不会在模型不可用时生成离线假回答。
- 模型输出可能错误，必须人工复核。
- 金融计算保持在代码层，LLM 不参与算术。
- 上下文会做压缩，减少 Token 消耗。

## 插件安全

- 插件在浏览器沙箱中执行。
- 有超时和输出限制。
- 未通过质量门禁的插件不会自动激活。
- 被隔离的插件不会参与执行。
- 请勿安装来路不明的插件代码。

## 备份建议

建议定期导出：

```text
设置 → 导出全部配置
```

备份文件包含：

- 岗位与人物
- 会话记录
- 先哲配置
- 插件
- 投资运行
- 模型配置和 API Key

请不要把备份文件分享给他人。

## 清除数据

### 清除页面数据

浏览器开发者工具 → Application → Storage → Clear site data。

### 恢复默认

应用内：

```text
设置 → 恢复默认
```

### 手动清理媒体

删除对应笔记或媒体附件时，系统会同步删除 IndexedDB 中的 Blob。
