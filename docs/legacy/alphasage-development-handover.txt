第一部分：项目定义
1.1 项目目标
构建一套多智能体投资分析系统，把投资决策拆解为可独立计算、可独立验证的原子判断。

核心设计哲学：

自上而下漏斗：宏观（有没有水）→ 行业（钱往哪流）→ 公司（买哪只）→ 技术（何时买）→ 情绪（氛围）

纯代码计算：所有金融算术用 pandas/numpy 完成，LLM 只做逻辑推演

多智能体对抗：每个判断由独立角色产出，compliance 有一票否决权

留痕优先：所有决策保留历史沿革，不覆盖、不删除

1.2 交付形态
41 个业务插件（当前 18 个 done）：每个插件是一个独立的 Python 包，输入 DataFrame，输出结构化 AgentVerdict

契约体系：AGENTS.md + plugin-manifest.yaml + data-columns.yaml，三者构成唯一事实来源

门禁体系：check_contract.mjs（结构契约）+ gate.ps1（一键跑全部门禁）

采集层（未完成）：从申万/东财拉真实数据，喂给插件

第二部分：核心设计原则（不可违背）
2.1 三条防幻觉铁律（R1/R2/R3）
编号	内容	机械判据
R1	所有金融计算纯代码，严禁 LLM 参与算术	AST 扫描禁用符号（socket/requests/akshare/openai 等）0 命中
R2	数据缺失时返回固定状态 INSUFFICIENT_DATA，value=None，不得编造数值	所有不足路径返回 {samples, reason} 两键，message 精确为「数据不足，暂不决策」
R3	每插件恰好 3 个 pytest 用例，不得引入未声明依赖	AST 计数 test_ 函数 == 3；依赖 ⊆ pyproject
compliance 对这三条有一票否决权。

2.3 留痕纪律
所有被取代的旧文本保留原行，就地追加取代标注

不删除历史，不覆盖原句

废止理由必须留下，不得整段删光

台账记录所有并发覆盖事件

2.4 引用纪律（§8）
引用一律「章节号 + 内容片段」，不得只写裸行号

确需行号时必须标注 @<commit hash>（如 L352@f1034db）

审查报告引用行号时必须同时给出内容片段

存量不合规旧引用不追溯重写，但不得再被复制

4.3 data-columns.yaml（列定义）
