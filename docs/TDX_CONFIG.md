# 通达信行情源配置说明

## 融合方式

通达信配置现在保存在应用全局状态 `AppState.tdx` 中，不再只在投资分析面板里单独维护。

- 设置中心：新增「通达信行情源」配置区，可以查看来源、更新时间并修改配置。
- 投资分析：直接读取同一份 `AppState.tdx` 配置，不再单独保存副本。
- 全量备份：`exportState` 会包含通达信配置；导入备份后也会还原。
- 版本升级：旧版本保存在独立 localStorage 里的自定义配置，会在启动时自动迁移到全局状态。
- 安全边界：只解析 `[HQHOST]` 行情主站，只读取 K 线和报价数据；不保存、不读取、不提交账号密码或交易接口参数。

网页版和开发服务通过 Vite 本地桥读取行情；打包后的桌面版通过 Electron IPC 调用同一套只读协议，无需另起本地服务。

## 自动识别

桌面端启动投资分析时会优先探测本机通达信配置：

1. 环境变量 `EVO_TDX_CONFIG` 指定的路径。
2. 默认路径 `D:\我的专用灵动版V1.21\Connect.cfg`。

如果找到本机配置，配置来源会显示为 `tdx`，并记录原路径。如果未找到，则使用内置默认配置 `public/tdx/Connect.default.cfg`。

用户一旦保存自定义配置，来源会变成 `custom`；此后不会再被本机默认探测覆盖，直到点击「恢复默认」。

## 编辑入口

- 「设置 → 通达信行情源 → 修改配置」。
- 「投资分析 → 通达信行情源 → 修改配置」。

两个入口编辑的是同一份配置。设置中心保存时会先调用解析接口检查是否存在行情主站；投资分析保存后可继续点击「连接行情源」探测并读取日 K。

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `[USER]` | 保持空用户名、`SavePass=0`，用于声明不登录。 |
| `[HQHOST]` | 行情主站组，当前实际读取 K 线和报价的核心配置。 |
| `HostNum` | 行情主站数量，需要与实际条目数量一致。 |
| `PrimaryHost` | 首选主站编号；系统仍会自动探测并切换。 |
| `HostNameNN` | 主站显示名称。 |
| `IPAddressNN` | 主站地址，支持 IP 或域名。 |
| `PortNN` | 主站端口，常见为 `7709`，少量站点使用 `80`。 |
| `[INFOHOST2]` | 资讯主站组，当前仅解析展示。 |
| `[DSHOST]` | 扩展市场数据站组，当前仅解析展示。 |

## 禁止添加

- `[WTHOST]`、`[USERHOST]`
- 交易服务器地址
- 账号、密码、证书
- 自动下单或自动交易参数

本软件不会修改通达信原目录中的 `Connect.cfg`。
